Jawab Misi 1 (Pertanyaan Teori di LKPD Halaman 2)
1. Apa fungsi GitHub Issue? Jawaban: Untuk mencatat tugas, fitur yang akan dibuat, bug, serta memantau perkembangan/progres pengerjaan proyek dalam tim secara terstruktur.
2. Mengapa pekerjaan sebaiknya dicatat sebagai Issue? Jawaban: Agar setiap anggota tim tahu pasti tugas masing-masing, siapa penanggung jawabnya, dan mencegah terjadinya pengerjaan ganda (bentrok).
3. Apa perbedaan Issue dengan Commit? Jawaban: Issue adalah deskripsi RENCANA/TUGAS pekerjaan yang akan dilakukan, sedangkan Commit adalah CATATAN PERUBAHAN KODE nyata yang sudah disimpan/diketik.
